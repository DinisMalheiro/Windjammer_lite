# Windjammers Lite

## Description
Windjammers Lite is a small remake of the arcade game Windjammers.
The player controls a character on a court and throws a disc towards the opponent's side to score points.
The project is being developed in C using Raylib, with a focus on recreating the basic movement, animation and arcade gameplay of the original.

**Version**

    Alpha 1.0

**CONTROLS:**

    a - go up
    w - go down
    s - go right
    d - go left
    space - throw disk
    enter & esc & awsd - menu navigation
